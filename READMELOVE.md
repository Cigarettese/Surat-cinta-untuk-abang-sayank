# Surat Cinta untuk Abang Sayang

**Web sederhana ini Yarka buat spesial untuk Yuda, cinta hati Yarka.**  
Isinya nggak banyak, tapi semuanya tulus dari hati.  
Dari awal ketemu sampai sekarang, rasa ini makin kuat. Web ini cuma cara kecil Yarka nunjukin rasa itu.

## Fitur
- Tampilan pink manis, kayak rasa sayang Yarka ke Yuda.
- Input nama/kode dulu, biar makin misterius dan spesial.
- Begitu berhasil, muncul surat cinta buatan Yarka.
- Ditemani musik romantis, biar makin baper bacanya.
- Ada animasi hati terbang, karena cinta ini nggak pernah diem.

## Cara Pakai
1. Buka web-nya (bisa klik link GitHub Pages kalau udah dideploy).
2. Masukkan nama/kode rahasia (Yuda pasti tahu jawabannya).
3. Tekan tombol "Buka Surat".
4. Baca suratnya sambil dengerin lagu kesukaan kita!

## Dibuat Dengan
- HTML, CSS, JavaScript
- Dan... cinta, kangen, serta rasa sayang Yarka yang nggak bisa dijelasin pakai kata
